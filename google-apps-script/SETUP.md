# Google Sheets 收集配置

1. 新建一个 Google Sheet。
2. 打开“扩展程序 → Apps Script”，将 `Code.gs` 的内容粘贴进去并保存。
3. 选择“部署 → 新建部署 → Web 应用”：
   - 执行身份：我
   - 谁可以访问：所有人
4. 完成授权并复制以 `/exec` 结尾的 Web 应用地址。
5. 将 `index.html` 中的 `SUBMIT_URL` 替换为该地址。
6. 先用测试数据完成一次完整问卷，确认 `Results` 工作表新增 30 行，再发布网页。

更新 Apps Script 代码后，需要编辑现有部署并选择“新版本”，否则线上仍会运行旧代码。

## 数据与运维说明

- `participantId` 是浏览器本地生成的匿名 UUID；清除站点数据或更换浏览器会得到新 ID。
- `submissionId` 用于后端去重；Apps Script 使用脚本锁避免并发提交互相覆盖。
- 前端使用 `no-cors` 发送请求，浏览器无法读取 Apps Script 的返回值。因此页面显示“请求已发送”不等于已从服务器确认写入；试运行期间应检查 Sheet 和 Apps Script“执行记录”。
- `/exec` 地址是公开写入入口。后端会校验字段与每次 30 行的数量，但它不能阻止有意构造的垃圾请求。公开招募或大规模研究建议增加一次性参与码，或改用带鉴权的后端。
- 不要在负载中加入姓名、邮箱、IP 等直接身份信息，除非知情同意文本和数据管理方案明确覆盖。
